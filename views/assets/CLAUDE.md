# Styles, fonts and the service worker source

- **CSS**: Tailwind v4 (`@tailwindcss/cli`) + daisyUI. Source `views/assets/main.css`, compiled to `public/bundle.css` by `npm run generate:tailwind`. **Theme (R1, #81; the owner chose "Atelier", 2026-09-27):** two daisyUI themes in `main.css`, `closet-light` (default) and `closet-dark` (follows `prefers-color-scheme`, no toggle), daisyUI's built-ins off; flat (no shadows), 1px borders, the plan's radii; `base-200` is the one neutral plinth behind cutouts; `accent` is the clay. `src/web/theme-colors.ts` holds base-100 as hex for the manifest and the two `<meta name="theme-color">` tags (a unit spec fails if it drifts from main.css's oklch). **Fonts:** Inter (UI) and Fraunces (headings), `@fontsource-variable`, Latin subset, weight axis only, `font-display: swap`; `npm run generate:fonts` (inside `generate:vendor`) copies content-hashed woff2 into `public/vendor/fonts/` and writes the generated, git-ignored `fonts.css` that `main.css` imports, so **the fonts step must run before Tailwind**: `generate:tailwind` and `generate:tailwind:watch` run `generate:vendor` first themselves (#119), so no caller has to remember it; the service worker precaches `woff2`.

`src-sw.ts` is the service worker: its doc is `src/web/shell/CLAUDE.md` (PWA and the service worker).
